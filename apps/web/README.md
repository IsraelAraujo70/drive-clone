# Web App

TypeScript frontend for the Google Drive clone.

Current scope:

- Vite + React + TypeScript scaffold.
- Health status call against the deployed API.
- Static production build deployable to Railway.

Local commands:

```bash
npm install
npm test
npm run build
npm run dev
```

Environment:

- `VITE_API_BASE_URL`, default `https://api-production-bcad4.up.railway.app`
